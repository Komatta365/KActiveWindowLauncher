# ADR 0003: dnd-kit の DragOverlay を採用する

- Status: Accepted
- Date: 2026-08-31

## Context
- ランチャースロットの並べ替えでは、ドラッグ中に「何を掴んでいるか」を視覚的に明確化する必要がある。
- 移植元は専用カーソル/ドラッグ表示を持っており、移植先でも同等以上の操作性が必要である。
- dnd-kit を採用する前提で、ドラッグ中の描画方式を決める必要がある。

## Decision
- スロットの並べ替え UI は **dnd-kit** を使用する。
- ドラッグ中の視覚表現は **DragOverlay** を標準方式として実装する。
- Overlay には元スロットと同一のアイコン/状態を描画し、元位置側はプレースホルダ表示にする。

## Consequences

### Positive
- ドラッグ対象が明確になり、誤操作を減らせる。
- DnD 表示ロジックを dnd-kit の推奨パターンに沿って実装できる。
- 将来のアニメーション調整やアクセシビリティ拡張が行いやすい。

### Negative / Trade-off
- Overlay 用の描画コンポーネント管理が追加で必要になる。
- センサー設定（Mouse/Touch/Keyboard）と組み合わせた調整が必要になる。

## Notes
- Overlay は最初にデスクトップ（マウス）操作を優先し、必要に応じてキーボード DnD を段階的に追加する。
